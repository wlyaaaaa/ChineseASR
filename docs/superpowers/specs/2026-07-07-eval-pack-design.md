# Eval Pack Design

## Goal

Build a reproducible local evaluation path for ChineseASR that does not require private user recordings. The evaluator should stress normal Chinese transcription and hallucination boundaries with generated samples, then report metrics and review targets.

## Scope

- Add a built-in corpus generator for local TTS speech samples and non-speech adversarial samples.
- Add an evaluation runner that reuses existing strict transcription bundles.
- Add metrics and Markdown reports: `metrics.json`, `benchmark.md`, and `review.md`.
- Add CLI and PowerShell wrappers.
- Do not add GUI, API service, file watchers, network datasets, or private sample assumptions in this iteration.

## Corpus

The generated corpus lives under a user-selected directory such as `eval/corpus/builtin`.

Positive samples:
- Windows SAPI / System.Speech TTS Chinese speech when available.
- Truth text is known before generation.
- Optional noisy variants may be generated by mixing deterministic low-level noise into TTS WAV files.

Negative samples:
- Silence.
- Deterministic white noise.
- Tone / non-speech audio.
- Truth text is empty and `expect_empty` is true.

If TTS is disabled or unavailable, the corpus still contains adversarial samples and records unavailable TTS samples as skipped rather than pretending silence is speech.

## Evaluation Flow

1. Read `manifest.json`.
2. For each available case, run existing strict transcription into a per-case output directory.
3. Read `*.strict.audit.json`.
4. Compute:
   - `cer`
   - `disagreement_score`
   - `empty_audio_text_len`
   - `risk_flags`
   - `false_confident`
   - `simplified_only`
5. Write:
   - `metrics.json`
   - `benchmark.md`
   - `review.md`

## Success Criteria

- Unit tests do not load ASR models.
- `zh_asr eval --generate --generate-only --no-tts` creates a usable adversarial corpus.
- Evaluation can be tested with injected fake strict transcribers.
- PowerShell wrapper clears proxy variables before running.
- Generated audio and run outputs are ignored by Git.
