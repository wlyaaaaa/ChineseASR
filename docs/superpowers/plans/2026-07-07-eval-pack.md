# Eval Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a privacy-free evaluation pack that generates local synthetic/adversarial samples and reports ASR hallucination metrics.

**Architecture:** Add `zh_asr.eval_pack` as a focused module for corpus generation, metric computation, and evaluation orchestration. Wire it into `zh_asr eval` and `scripts/eval.ps1`; reuse existing strict transcription instead of duplicating ASR logic.

**Tech Stack:** Python 3.11 standard library, PowerShell System.Speech on Windows, existing `strict_transcribe_audio`, unittest.

## Global Constraints

- Do not require private user recordings.
- Do not require network datasets in v1.
- Do not route downloads or model calls through proxy variables.
- Unit tests must not load ASR models.
- Generated corpus audio and run outputs must be Git-ignored.
